## 14. Wrap-up

Compare scoreboards with the people around you.

Key teaching point: the workshop is not "build a flow". It demonstrates an improvement cycle: run real examples, collect human review decisions, leave trace feedback, revise the agent and the orchestration logic, then add automation only where the evidence supports it. The three batches contain different tickets, so the falling count shows routing behavior, not a controlled accuracy benchmark.
